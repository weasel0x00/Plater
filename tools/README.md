# Plater tools

Helper scripts for working with [Plater](../README.md).

## gen_plater_conf.py

Generates a Plater configuration file (`plater.conf`) from a directory full of
STL parts, so you don't have to list every part and quantity by hand.

It scans the directory for `.stl` files and writes one line per part —
`<filename> <quantity>` — which is exactly what Plater's CLI expects (see
*"The plater.conf file"* in the main README).

### Naming rules

The script honors two conventions encoded in the file names:

* **Quantity — `_x<N>` suffix.** If a part's base name (before the extension)
  ends with `_x<number>`, it is listed that many times. For example
  `cable_anchor_x9.stl` becomes `cable_anchor_x9.stl 9`. Everything else gets a
  quantity of `1`.
* **Accent parts — `[a]` prefix.** Files whose name starts with `[a]` are written
  to a **separate** config file (`accent_parts.conf` by default) instead of the
  main `plater.conf`. This is handy when a subset of parts is printed differently
  (e.g. a different color/filament) and you want to plate them on their own.

The original file names are preserved in the config (the markers are part of the
real file names on disk); spaces in names are escaped automatically.

### Usage

```
python3 gen_plater_conf.py <directory> [options]
```

The config files are written **inside** `<directory>` (Plater resolves part
paths relative to the config file, so the config must live alongside the STLs).

| Option | Default | Description |
| --- | --- | --- |
| `-o`, `--output` | `plater.conf` | Name of the main config file |
| `-a`, `--accent-output` | `accent_parts.conf` | Name of the accent-parts config file |
| `-e`, `--ext` | `.stl` | File extension to include (case-insensitive) |

The accent config is only created when at least one `[a]`-prefixed part exists.

### Example

For a directory like:

```
TridentR2/
  main_body.stl
  cable_frame_anchor_x9.stl
  idler_housing_x2.stl
  [a]_xy_left.stl
  [a]_cover_logo_x2.stl
```

running:

```
python3 tools/gen_plater_conf.py TridentR2
```

produces `TridentR2/plater.conf`:

```
# Plater main parts
# Generated by gen_plater_conf.py -- 3 part type(s)
cable_frame_anchor_x9.stl 9
idler_housing_x2.stl 2
main_body.stl 1
```

and `TridentR2/accent_parts.conf`:

```
# Plater accent parts
# Generated by gen_plater_conf.py -- 2 part type(s)
[a]_cover_logo_x2.stl 2
[a]_xy_left.stl 1
```

You can then plate them, e.g.:

```
plater -W 300 -H 300 -A pruned -m -O TridentR2 TridentR2/plater.conf
```
